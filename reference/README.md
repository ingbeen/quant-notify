# reference — 다른 저장소에서 가져온 참고 문서

이 폴더는 **읽기 전용 참고 자료**입니다. 알림이 무엇을 판정해야 하는지의 근거가 여기 있습니다.

## 이 폴더의 규칙

- **여기서 고치지 않습니다.** 정본을 고친 뒤 다시 복사합니다
- **품질 검사(Ruff · PyRight · pytest) 대상이 아닙니다** — `pyproject.toml` 과 `pytest.ini` 에서 제외돼 있습니다
- 문서 안의 **링크와 파일 경로는 정본 저장소 기준이라 열리지 않습니다.** 내용을 읽는 용도입니다
- 알림 구현은 이 문서를 읽고 `src/notify/` 에 새로 작성합니다. 코드를 복사해 오지 않습니다

## 스냅샷이 낡는 것을 어떻게 아나

**자동으로는 알 수 없습니다.** 정본이 갱신돼도 이 사본은 조용히 그대로 있습니다.

## 언제 지우나

`src/notify/` 의 대응 알림이 완성되고 규격이 코드와 테스트로 고정되면 참고 가치가 줄어듭니다.
다만 **판정 근거를 다시 읽어야 할 일이 계속 생기므로** 서둘러 지우지 않습니다.
